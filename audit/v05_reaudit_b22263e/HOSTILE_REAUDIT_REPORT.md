## VERDICT

**V0.5 POST-REMEDIATION HOSTILE RE-AUDIT — REMEDIATION REQUIRED**

### Basis

1. **RA-000 (BLOCKER, reproduced): the candidate cannot be independently audited.** b22263e, cfcff3d and
   the stage commits exist only on the Windows host. The remediation report, the controlling audit with
   its 17 repro probes, the oracle directory and the Expedition C material are local files there.

   Every route available to this re-audit was tried, and the evidence is recorded:
   - Git refs, and fetch by full SHA;
   - the GitHub commit API;
   - pull requests;
   - the connected Drive.

   Not one of the 25 mandatory attack areas could be executed against b22263e. c8dfafd makes
   certification depend on an independent hostile review (§16.5 AC-9), and its doctrine is that a failure
   "never passes by omission" (§11.5). Under that rule, certifying unexamined code GREEN is not available.
   The remediation is procedural: publish the candidate and the controlling material, then run the
   prepared re-audit (`REPRO_COMMANDS.md` §B–§C).
2. **RA-001 (MEDIUM, CERTIFICATION GAP): the real-symlink credential test still skips**, by the
   implementer's own report. Under c8dfafd it is a certification gap, not a non-blocking external check:
   §16.2 makes "a GREEN secret-handling suite" the prerequisite of G1, and V0.5 certification exists to
   satisfy it (`SYMLINK_GAP_ASSESSMENT.md`). It would block GREEN even if b22263e were reachable and
   otherwise clean.

### What this verdict does NOT say

It does **not** say that b22263e contains a code defect. No code of b22263e was seen. None of the prior
BLOCKER classes is classified STILL REPRODUCIBLE or REGRESSED, and none is classified CLOSED; all are
**NOT DETERMINABLE** (`PRIOR_FINDING_CLOSURE_MATRIX.md`). The implementer's results are neither confirmed
nor refuted. "Green" claims from the implementer were not used as evidence, as the mission requires.

### Independence disclosure

This session runs on the Claude model family. The 37b86fb audit and, by their trailers, the V0.5
implementation commits also came from Claude sessions. No implementer artifact was available to this
session (no transcript, report, test or helper), so none was relied on. The prior 37b86fb package was used
only as follows:

- its **oracle**, regenerated byte-identically from the frozen code, to confirm it is a sound yardstick;
- its **attack scripts**, as an inventory of the cfcff3d public API that the new probes bind to.

Whether this meets the AC-9 independence standard is for the human owner to decide.
